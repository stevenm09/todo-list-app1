# To-Do List App

Aplikasi daftar tugas sederhana berbasis web. Tugas tersimpan di peramban (localStorage), jadi tidak hilang saat halaman dimuat ulang.

## Fitur
- Menambah tugas baru
- Menandai tugas selesai atau belum
- Menghapus tugas
- Filter: Semua, Aktif, Selesai
- Penghitung tugas yang tersisa dan tombol "Hapus yang selesai"
- Tampilan responsif untuk layar ponsel

## Teknologi
HTML, CSS, JavaScript (tanpa framework)

## Cara menjalankan
Unduh folder ini, lalu buka `index.html` di peramban. Tidak perlu instalasi apa pun.

## Yang saya pelajari
- Manipulasi DOM dan penanganan event
- Menyimpan dan membaca data dengan `localStorage`
- Memisahkan data (array), logika, dan tampilan (fungsi `render`)
